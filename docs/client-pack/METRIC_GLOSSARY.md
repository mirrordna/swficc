# Dashboard Metric Glossary

This glossary explains the dashboard terms in business language. It intentionally avoids internal endpoint, database, and implementation terms.

## Top AUM Ranking

Shows the disclosed AUM scale represented by the top ranked institutions shown in the dashboard. It should not be read as a universe-wide total unless SWFI explicitly provides that basis.

## Active Allocators

Shows institutions with recent buyer/acquirer-side transaction activity during the selected activity window. The dashboard summary uses recent activity to show who is active now, not stale historical participation.

## Disclosed Deal Value

Shows transaction value only where amounts are disclosed and comparable in the displayed data. Undisclosed amounts should not be estimated or filled in.

## Live RFPs / Mandates

Shows currently active opportunities, mandates, or RFP-style records that are available for discovery and navigation.

## SWF Profiles

Shows the number of sovereign wealth fund profile records available in the displayed dashboard summary.

## Intelligence Items

Shows available intelligence/news/research items surfaced for discovery.

## Total Institutions Tracked By Entity Type

Groups institution/entity coverage by business type so users can understand platform coverage without browsing raw records.

## Top Active Investors

Ranks investors by recent deal activity in the dashboard window. Ranking should consider deal count first, then disclosed deal value and recency where available.

## Recently Fundraising Institutions

Highlights institutions attached to current fundraising, mandate, or opportunity activity.

## Investment Trends By Industry / Category

Summarizes transaction activity by industry/category so users can see where capital activity is concentrated.

## Market Signals

Combines key dashboard signals, such as active investors, recent deals, open mandates, and new intelligence, into a quick-read panel.

## Data Quality Rule

If a value is unavailable, stale, or not validated, the dashboard should hide or block the module rather than invent a number.
