7 Dashboard Requirements
7.1 User Experience Requirements
User should be able to:
   1. See institutional investor overview through key KPIs
   2. Identify active investors
   3. Understand market and investment trends
   4. Drill into relevant opportunities
   5. Take action directly from the dashboard
All of the above should be achievable within a single dashboard screen.


                                                                          8
7.2 Platform Integration Requirements
The dashboard shall not reinvent the wheel. It shall function as both an institutional investor intelligence layer and a
gateway into the existing SWFI platform.
The dashboard shall not simply regurgitate information that already exists elsewhere in the system. Instead, it should
highlight, synthesize, and contextualize existing SWFI data in a way that helps users quickly understand institutional
investor activity, identify relevant institutions, and navigate to deeper platform assets when needed.
Information presented in the dashboard should remain tightly integrated with existing SWFI platform assets, such as
profile pages.
For example, ranked lists such as sovereign wealth funds by assets under management should be displayed in tabular
form, with each row hyperlinked directly to its corresponding SWFI profile page.
The same principle should apply to charts and visualizations. Chart elements, data points, labels, or underlying records
should link back to relevant SWFI profile pages, lists, datasets, transactions, or other existing platform assets where
applicable.
