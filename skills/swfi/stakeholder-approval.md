# SWFI Stakeholder Approval

Content changes require KP approval unless a newer stakeholder matrix supersedes this rule.

Approval artifacts must include:

- approver,
- timestamp,
- requested action,
- scope,
- draft or correction id,
- before/after diff where applicable,
- allowed final action,
- expiration or one-time-use marker,
- receipt id.

Approval is required for:

- publishing,
- outbound communications,
- production record correction,
- private-data release,
- access-control changes.

An agent may request approval. An agent may not fabricate approval.
